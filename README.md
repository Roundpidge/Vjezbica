# Vjezbica

To use this web app you need to have these dependancies installed:
  -Node.js
  -Nodemon
  -Express.js

How to start web app localy?
  1) Find folder which has index.js
  2) -Type in terminal: nodemon index.js
     -If you dont have nodemon installed, just type: node index.js
  3) You can see your web app by copying and pasting into browser: http://localhost:3000/

  Have fun testing!
